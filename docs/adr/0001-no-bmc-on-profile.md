# ADR 0001 — Sem Buy Me a Coffee no README do perfil

- **Status:** Aceito
- **Data:** 2026-08-15
- **Autor:** Leonardo Bora (The Neuromancer)

## Contexto

A skill `github-readme-badges` (norma 1) determina que *todo* README gerado ou atualizado deve incluir o botão Buy Me a Coffee. A norma foi escrita para READMEs de **projetos** (repos de software). O README do **perfil** (`leonardobora/leonardobora`) é diferente: não é a vitrine de um projeto, é a vitrine profissional do autor — e o autor *é* o beneficiário do BMC.

## Decisão

**Não** incluir o botão Buy Me a Coffee no README do perfil GitHub. A norma "sempre BMC" da skill aplica-se somente a READMEs de projetos.

## Consequências

- **Positivas:** o perfil mantém o tom de vitrine profissional (recrutadores não veem botão de doação no topo); evita destoar do objetivo "clareza > quantidade".
- **Negativas:** quem lê a skill de README sem este ADR pode "corrigir" o perfil adicionando o BMC — este documento explica por que não.
- O botão BMC **permanece** em todos os READMEs de projetos (b0r4-watch, mcp-wordpress, etc.), onde a norma se aplica.

## Alternativas consideradas

- **Incluir o BMC no perfil:** rejeitado — o perfil é vitrine profissional, não página de doação.
- **Link discreto no contato:** rejeitado — o perfil não arrecada doações; os projetos são quem recebe apoio.
